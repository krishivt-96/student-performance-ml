# 🎓 Student Performance Predictor

A Machine Learning web application that predicts student math scores based on demographic and academic features.

## 🚀 Features
- Predicts math score using ML model
- Built using Random Forest Regressor
- Interactive UI using Streamlit

## 🧠 Tech Stack
- Python
- Pandas, Scikit-learn
- Streamlit

## 📊 Model Performance
- R² Score: ~0.84

## ▶️ Run Locally
```bash
pip install -r requirements.txt
streamlit run app.py
